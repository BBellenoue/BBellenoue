### What I work on

I lead the core engineering team at [Eloficash](https://eloficash.com), where most of my
attention goes to one thing: turning Generative AI and LLMs from individual
experimentation into an industrial practice inside the development lifecycle. Shared
tooling, an explicit usage framework, and adoption support, rather than a licence handed
out and forgotten.

That work produced a few things I care about:

- A private internal Claude Code plugin marketplace: a shared, versioned catalogue that
  turns individual AI tooling into a governed platform every team can build on.
- A multi-agent development workflow whose agents mirror the team's actual technical
  roles, so the pipeline follows how the organisation really builds.
- Agents that extend their own capabilities from usage, so the tooling compounds instead
  of freezing at delivery.

The hard part is never the tooling. It is adoption, governance, and knowing which parts
of the lifecycle should not be automated. Review discipline matters more once generation
is cheap, not less.

I still ship production code. It keeps architectural judgement honest.
